这次构建没有内置服务地址。骨架把地址编译进打包资源：第 3 步生成 www/js/mobile-env.js，里面就是本页读取的 window.ICHAT_MOBILE_ENV。App 运行时不从服务器或设置页取地址， 所以重装同一个安装包不会改变本页——必须按下面的步骤重新生成并打包。

运行时地址注入（安装后在 App 内配置、或由服务端动态下发）尚未实现， 属于 P4 T23/T24 之后的工作；本页只保证构建期注入这条路径可用。

在仓库里按顺序执行（PowerShell，需 JDK 21+ 与 Android SDK）：

  1. cd mobile
  2. $env:ICHAT_MOBILE_SERVER_URL = "https://chat.example.com:8443"
  3. npm run config:generate
  4. npx cap sync android
  5. cd android，然后 .\gradlew.bat assembleDebug

第 3 步同时重写 capacitor.config.json（发布模式仍不含 server 块）； 第 4 步把 www/ 复制进原生工程，漏掉它 APK 里仍是旧资源。 生成器只读进程环境变量，不读 mobile/.env； 未设置变量时第 3 步以退出码 1 结束，两个文件都不写。 生成后的 www/js/mobile-env.js 是构建产物、已被 gitignore， 形态参考 www/js/mobile-env.example.js。
