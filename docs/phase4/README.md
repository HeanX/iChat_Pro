## 1. 本次 Phase4 的口径

本目录采用 2026 年 9 月软件测试实践的 Phase4：**Windows/Android 产品化、公网云部署、可靠通信、E2EE 增强与测试工程**，沿用 `P4 T01–T54` 和 `P4 Test T01–T24` 的 78 项任务编号。

早期文档把 Phase4 定义为 Channel、Bot、LLM Agent、OpenClaw。这套生态规划不属于本目录的核心交付范围。不要因旧文档出现相同的 T41/T42 等编号就混用任务；引用任务时必须保留 `P4` 或 `P4 Test` 前缀。

本次未收到额外范围确认，依据最新课程资料采用上述口径。若用户后续明确要求生态扩展，应另建范围基线，不覆盖本目录任务编号。

## 4. 如何开始

建议先安排 WP00 基线、WP01 云端配置、WP02 协议可靠性、WP03 Windows、WP04 Android 技术验证。WP05 安全与 WP06 测试从第一轮就参与接口评审；WP07 CI 逐步接入已能执行的检查。

每个 Agent 只领取一个有明确文件边界的工作包，先交付该包 P0，再推进 P1/P2。共享的 `chat.js`、模型、迁移和依赖文件必须协调串行合并。工作包详情和完整提示词见 [交接文档](agent-handoff.md)。
